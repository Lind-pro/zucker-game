# 笔画书写

直接打开 `index.html`，或从“小小学习乐园”首页进入。运行时没有第三方网络请求。

- 18 种常见笔画：6 种基础笔画、6 种转弯笔画、6 种带钩笔画。
- 12 个简单汉字：一、二、三、十、人、大、口、日、田、木、山、水。
- 点读本地音频，田字格逐笔动画，暂停、重播、单笔演示、慢速播放。
- 描写使用 Hanzi Writer 的笔形和方向检查，支持回退一笔、清空、起笔点、错误提示。
- 每轮 5 道听音选择题，不自动跳题；本机保存学习记录与星星。首次写好每个条目加星，回退重复书写不重复加星。

`data.js` 定义课程、笔画名称、原始字符和零起始笔画序号。`character-data.js` 是生成的离线笔顺数据。动画和识别复用固定版本 Hanzi Writer 3.7.3，样式与图标复用相邻的 `pinyin/` 资源。原有拼音页面不作改动。

## 更新资源

需要 Node.js、curl、ffmpeg。首先在 `scripts/` 执行 `npm ci`，随后执行 `npm run assets`。该命令下载固定版本的字形、许可证和音节录音，并用 svgpath 解析、等比缩放基础笔画路径。不要手工编辑生成数据。

资源来源、作者、修改说明和许可见 `credits.html` 与 `vendor/`。复合笔画名称音频为真人音节拼接；操作引导语音依赖设备是否有普通话语音。核心点读无需设备安装语音。

网页支持 `file://` 和普通静态托管。没有注册 Service Worker；托管页面的离线可用性取决于浏览器缓存。

## 检查

安装 Playwright 与 Chromium 后运行 `node tests/smoke.cjs`。也可以将 `PLAYWRIGHT_MODULE` 指向已有 Playwright 模块。检查全部 30 个条目的描写、录音解码、错误方向、暂停、回退、听音练习、存储、声音重试、触屏中断以及 320/390/768/1280 像素布局。截图输出到临时目录。
