# 拼音启蒙

直接打开 `index.html` 即可使用，不需要构建或在线服务。首页入口位于上级“小小学习乐园”。

- 54 个学习条目：6 个单韵母、21 个声母、y/w、8 个复韵母和 er、16 个整体认读音节。
- 点读使用本地真人录音；6 个单韵母支持四声。辅助操作提示使用设备的普通话语音，设备没有普通话语音时仍可点读本地录音。
- 手写路径在四线三格中逐笔播放，可暂停、重播、单笔演示、慢速播放。
- 描写按顺序检查起点、轨迹覆盖、方向与终点，使用 SVG 屏幕坐标变换适配缩放和触屏。支持撤回上一笔和清空。
- 听音练习每轮 5 题，不限重试，不自动跳题。学习记录只存储在当前设备。
- `file://` 和普通静态托管均支持；没有注册 Service Worker，远程网站离线时仍受浏览器缓存情况影响。

## 内容与资源

`data.js` 是手写路径、分组和录音的唯一数据源。i 加声调时去掉点；ü 加声调保留两点。a/g 使用单层手写体。

声母以第一声呼读音示范，不能把它当成拼读时的短促本音。y/w 单列，不计入 21 个声母。ui/iu 使用完整独立音节 wei/you 的读音。此版本为基础启蒙，不包含鼻韵母全集和两拼/三拼教学。

音频源：Chen Wang / Hugo Lopez / Nicolas Vion, [Audio-cmn](https://github.com/hugolpz/audio-cmn)，CC BY-SA（上游未注明版本）。文件从提交 `ff9ed3d0c631195bd2c06f39450f3264c7124040` 的 `64k/syllabs/cmn-{name}.mp3` 原样复制，只去掉文件名前缀。完整作者说明见 `credits.html`。图标使用 Lucide，ISC 许可见 `vendor/LICENSE`。

下载脚本：`node scripts/download-assets.mjs`。它只下载清单内的音频及固定版本的 Lucide；不发送用户数据。页面运行时不请求第三方资源。
